- On definit une fonction en python en mettant le keyword `def`
```python
def nom_de_fonction(parm1, parm2):
    # CODE
```
- Il est possible de passer des paramettre de fonction en format **key = value**
```python
nom_de_fonction(parm1 = 1, parm2 = "String")
```
- Une fonction peux retourner une valeur de tous type"" si le keyword `return` est utiliser avec la valeur qui sera retourner
