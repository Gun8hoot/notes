### Operateur d'assignement
---
- Est representer par le character `=`
- Il permet de mettre la valeur dans la varible voulu 
- Il existe plein de type d'operateur d'affectation different
![img](https://github.com/Asabeneh/30-Days-Of-Python/raw/master/images/assignment_operators.png)

### Operateur arithmetique
---
- Addition : `+`
- Soustraction : `-`
- Multiplication : `*`
- Division : `/`
- Modulos : `%`
- Division entiere : `//`
- Exposantation : `**`

### Operateur de comparaison
---
- Egal : `==`
- Pas egal : `!=`
- Plus grand que : `>`
- Plus petit que : `<`
- Plus grand que ou egal : `>=`
- Plus grand que ou egal : `<=`
- operateur `is` : Nous permet de verifier si les deux variable sont le meme objet
- operateur `is not` : Nous permet de verifier si les deux variable ne sont pas le meme objet
- operateur `in` : Nous permet de verifier si un certain element est dans la list
- operateur `in not` : Nous permet de verifier si un certain element est dans la list

### Operateur logique
---
- Contrairement a 99% des autres language python n'utilise pas les operateur classique (||, &&, !) mais utilise des keyword
- operateur `and` : Retourne True si les deux comparaison son a True
- operateur `or` : Retourne True si une des deux comparaison est a True
- operateur `not` : Inverse le resulat de la comparaison
