- Chaque accumulateur est stocker dans une variable en **unsigned int**

- Calcul accumulateur 1 :
$$acc1 = ((seed + PRIME32\_1\ mod\ 32) + PRIME32\_2\ mod\ 32)$$
- Calcul accumulateur 2 :
$$acc1 = (seed + PRIME32\_1)\ mod\ 32$$
- Calcul accumulateur 3 :
$$acc1 = (seed + 0)\ mod\ 32$$
